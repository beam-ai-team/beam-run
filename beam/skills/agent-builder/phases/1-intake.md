# Understand a request

This is an on-demand discovery playbook, not a required phase.

Read the full request and extract the desired outcome, inputs, outputs, named
services, trigger, repetition, routing, and side effects. Search similar agents
when it helps prevent duplication. Do not ask the user to repeat a complete
brief or map their manual process unless it changes the proposed automation.

Ask one focused question only when it prevents a valid interpretation. Otherwise
state assumptions in the flow proposal and let the user correct them naturally.
