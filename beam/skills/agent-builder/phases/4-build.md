# Build a draft

After flow approval, read the spec format, node-authoring guidance, lint
checklist, and closest example spec. Write the spec, lint it, dry-run it, deploy
it, and verify links. These are internal integrity checks; report only concise
progress and the resulting draft status.

Do not publish as part of a build. Smoke-test only when the user asks or when a
verification failure needs isolation. If the platform lacks a smoke-test route,
report the limitation and offer task-level validation instead.
