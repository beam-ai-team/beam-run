# Repair an agent

This is an on-demand repair playbook. Attribute the issue to a node, parameter,
condition, prompt, model, or integration, then use the smallest patch. Show a
before/after diff when the repair is inferred or materially changes behavior.
Apply a direct, unambiguous user-requested repair without requiring a separate
command word.

Re-run the affected scenario and broaden regression testing only when it is
useful. Keep the draft unpublished unless the user explicitly asks to make it
live.
