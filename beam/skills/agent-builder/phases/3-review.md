# Approve a flow

This is the single user-facing checkpoint for a new or materially changed flow.

Show a Mermaid diagram, the confirmed integrations and triggers, any important
assumption, and whether the result will remain a draft. Ask whether that is the
intended agent. A clear ordinary-language approval authorizes creation or the
material draft change; do not require a command word.

For a minor prompt, tone, format, or model change to an existing draft, apply
the explicit request directly and report it without replaying the full flow.
