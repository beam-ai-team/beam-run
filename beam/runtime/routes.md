# Beam Run route index

Classify the requested outcome once, then load only that domain card. A graph mutation always routes to `agent-builder`; task execution and runtime consent remain task operations.

| Domain | Use when | Policy card | Operations card |
| --- | --- | --- | --- |
| `general-workspace` | Workspace-wide discovery, broad Beam questions, and unscoped work | `domains/general-workspace.md` | `operations/general-workspace.md` |
| `agent-builder` | Create or change a flow, node, trigger, webhook, or publish state | `domains/agent-builder.md` | `operations/agent-builder.md` |
| `agent-tasks` | One agent's task history, tests, retries, ratings, and task actions | `domains/agent-tasks.md` | `operations/agent-tasks.md` |
| `global-tasks` | Tasks spanning more than one agent | `domains/global-tasks.md` | `operations/global-tasks.md` |
| `agent-flow` | Read or explain a graph without changing it | `domains/agent-flow.md` | `operations/agent-flow.md` |
| `integrations` | Connections and custom integrations | `domains/integrations.md` | `operations/integrations.md` |
| `agent-config` | Settings, enabled tools, sub-agents, and context files | `domains/agent-config.md` | `operations/agent-config.md` |
| `agent-analytics` | Agent performance and exports | `domains/agent-analytics.md` | `operations/agent-analytics.md` |
| `inbox` | Notifications, task consent, and requested task input | `domains/inbox.md` | `operations/inbox.md` |
| `templates` | Template discovery, prerequisites, and creation | `domains/templates.md` | `operations/templates.md` |
| `views` | Saved Views, columns, records, and exports | `domains/views.md` | `operations/views.md` |
| `learning-hub` | Learning Hub issues, feedback, jobs, and tuning | `domains/learning-hub.md` | `operations/learning-hub.md` |
