# Contributing

This repository is the distribution home for the Beam agent plugin (skills, MCP
wiring, and the `beam` CLI launcher).

Issues and pull requests are welcome:

- Bugs / install failures → open an issue with your agent host (Claude Code / Codex / Cursor), OS, and the output of `beam whoami`.
- Skill or docs improvements → PRs preferred; keep changes small and reviewable.

Do not commit API keys, workspace secrets, or absolute `/Users/...` paths.
